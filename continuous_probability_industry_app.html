Exponential Distribution — Cloud Request Inter-arrival Time

A cloud server receives requests over time. Model the waiting time between consecutive requests.

Adjust request parameters

f(t) = λe−λt, t ≥ 0
F(t) = P(T ≤ t) = 1 − e−λt
P(T > t) = e−λt · Mean waiting time = 1/λ

λ is the average number of requests per second. A larger λ means requests arrive more frequently.

Central Limit Theorem — Warehouse Processing Time

Individual order-processing times may vary. The Central Limit Theorem helps estimate the distribution of the average processing time for a sample of orders.

Adjust warehouse parameters

X̄ ≈ Normal(μ, σ/√n)
Z = (deadline − μ) / (σ/√n)

For a sufficiently large sample, the distribution of sample averages is approximately normal. The standard error is σ/√n.
