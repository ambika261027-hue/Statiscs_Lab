AIML Lab: Discrete Probability Distributions

Discrete Probability Distributions

Welcome to the interactive Artificial Intelligence and Machine Learning (AIML) laboratory module dedicated to discrete probability distributions. In probabilistic modeling and statistical machine learning, understanding discrete random variables is fundamental for classification algorithms, probabilistic reasoning, language modeling, and stochastic processes.

How to use this lab: Select any module from the navigation bar above or via the cards below. You can dynamically adjust distribution parameters, compute exact PMF values and cumulative probabilities (CDF), visualize interactive bar charts featuring expected value markers, and complete guided laboratory exercises.

Binomial Distribution

Models the number of successes in a fixed number of independent binary trials (e.g., coin flips, binary classification correctness).

Poisson Distribution

Models the count of independent events occurring within a fixed interval of time or space at a constant average rate.

Geometric Distribution

Models the number of independent Bernoulli trials required to achieve the very first success.
